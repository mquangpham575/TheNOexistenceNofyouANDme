👁️ NOexistenceN

A "mostly functional" fan tribute to the aesthetic of MILGRAM. Expect glitches, existential dread, and occasional screen tearing.

🛠️ The Tech Stack (or what's holding this together)

- React + TS — Because I like types and headaches.
- Framer Motion — To make things jitter until they look intentional.
- Vite — To make the dev server start faster than my motivation.
